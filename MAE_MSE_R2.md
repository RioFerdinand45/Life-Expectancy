### MAE (Mean Absolute Error)

Menurut Web scikit-learn.org MAE mendekati 0 dan menjauhi 1 agar data dapat dipastikan bagus atau sempurna, jadi semakin kecil nilainya maka semakin kecil rata rata kesalahan prediksi model. Pada bagian mean_absolute_error dia menuliskan "The mean absolute error is a non-negative floating point value, where best value is 0.0."

### MSE (Mean Squared Error)

Menurut Web scikit-learn.org MSE mendekati 0 dan menjauhi 1 agar data dapat dipastikan bagus atau sempurna, jadi semakin kecil nilainya maka semakin kecil rata rata kuadrat kesalahan prediksi. Pada bagian mean_squared_error dia menuliskan "A non-negative floating point value (the best value is 0.0), or an array of floating point values, one for each individual target."

### R2 (Coefficient of Determination)

Menurut Web scikit-learn.org R2 mendekati 1 dan menjauhi 0 agar data dapat dipastikan bagus atau sempurna, jadi semakin besar nilainya atau bernilai 1 maka model menunjukkan prediksi yang sempurna pada data yang dievaluasi ketika bernilai 1. Pada bagian r2_score dia menuliskan "Best possible score is 1.0 and it can be negative (because the model can be arbitrarily worse)."
